OneHTML 私有服务器迁移包

本包含 Google OAuth 配置、账号数据库、作品文件和播放签名密钥。
只发送到你自己的服务器；本次不包含 GitHub 上传操作。
数据库为打包时已提交数据的一致性快照。

运行要求：Node.js 22.5 以上，推荐 Node.js 22 最新补丁版。
已带上跨平台运行依赖 jose；不包含 macOS 专用开发工具和 Node 可执行文件。

一、暂时用 IP 公开预览
1. 解压本包并进入 onehtml 目录。
2. 执行：bash scripts/start-ip.sh 你的服务器IPv4
3. 防火墙允许 TCP 4391、4392；访问 http://你的服务器IP:4391/
4. 播放器使用 你的服务器IP.sslip.io:4392，与主站隔离。需能访问 sslip.io DNS。
5. 此模式是 HTTP 临时预览；不要用它传输私人内容或登录密码。Google 登录在此模式下不可用。
6. 若需后台运行，可用进程管理器或：nohup bash scripts/start-ip.sh 你的服务器IPv4 > onehtml.log 2>&1 &

二、没有域名也继续使用已配置的 Google 登录（SSH 私有预览）
1. 在服务器的 onehtml 目录执行：npm run dev
2. 在自己的电脑关闭占用 4391/4392 的本地 OneHTML。
3. 在自己的电脑执行：bash scripts/tunnel.sh 用户名@服务器IP
4. 保持 SSH 终端打开，用浏览器访问 http://127.0.0.1:4391/
5. 这样两个端口都会转发到服务器，现有 Google 回调地址无需修改。

三、以后改成 HTTPS 域名
配置两个不同主机名的 SITE_ORIGIN 与 SANDBOX_ORIGIN，再运行 npm start。
Google 控制台需增加 SITE_ORIGIN/api/auth/google/callback 的完整地址。
反向代理须保留 Host；后端可设置 HOST=127.0.0.1。
若启用 TRUST_PROXY=1，代理必须覆盖 X-OneHTML-Client-IP，且后端只监听回环地址。

四、数据与维护
.data/onehtml.sqlite：账号、互动、审核、版本及会话数据。
.data/objects/：不可变 HTML 版本存档。
.data/play-secret：播放凭证签名密钥。
.dev.vars：Google 客户端配置。
private/google-client.json：原始 Google 客户端 JSON（提供时包含）。
备份和更新时保留 .data 与 .dev.vars；不要覆盖服务器新增的数据。
开发构建需先 npm ci；普通启动不需要重新构建作品。
